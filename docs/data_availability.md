# Data availability

The raw datasets used in this project are not distributed through this repository.

Excluded datasets include:

- raw airborne LiDAR
- DJI Zenmuse L2 point clouds
- Livox point clouds
- raw FigSpec FS60-C hyperspectral imagery
- DJI H30T thermal imagery
- high-resolution orthomosaics
- ArcGIS geodatabases

These files are excluded because of file size, licensing, data-access and project-management constraints.

Derived summary products, selected figures and processing scripts are included where appropriate.
